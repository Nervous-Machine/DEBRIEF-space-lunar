# Contributing to this record

A contribution is one dated cycle in `ledger/lunar.json`, under your own name. The rules, the four contribution
kinds and the templates are in the protocol repository:
https://github.com/Nervous-Machine/DEBRIEF/blob/main/CONTRIBUTING.md

For this mission the two most useful contributions are:

- **Surface dose data** (gap 1 in `ASKS.md`): the Data contribution issue form. See the README for the three steps.
- **Cycle 2** (gap 5): a pre-registered rerun of the Mars-to-Moon cross-check under the amended particle flag,
  reported with the Rerun report issue form.

A plain issue is fine for a question. Nobody edits a contributed cycle file after it is merged; a correction or
withdrawal is a new file.
